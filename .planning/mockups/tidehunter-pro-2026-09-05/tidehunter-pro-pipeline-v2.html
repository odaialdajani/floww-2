Every control in today's Tidehunter Pro and where it now lives. Nothing is dropped; things are moved or merged. moved marks a deliberate change.

Top bar

  • Brand, LIVE·CVFORGE chip → top bar
  • Three page buttons → removed; their content is folded into the pipeline (flow → drill-down, gamma → Dealers card + drill-down, scanner → screen bar + table)
  • Regime pill, clock, refresh → top bar
  • Quick filters (min score, DTE min/max, Clear) → Filters disclosure + active chips
  • Settings popup (poll interval) → Filters disclosure + gear

Scanner status tiles

  • Source, Contracts, Notional Σ, Call/Put, Unusual ≥2×, Updated, Heartbeat + budget tooltip → market tape
  • ⚡ Alerts count → verdict feed header (history count)
  • Simple / Advanced toggle → Filters disclosure + column chooser (saved per mode)

Alert layer

  • Fire banner (rule, contract, why, premium, σ, streak, age, ack) → Trade-now card + pinned feed row
  • Institutional alert tape (source dot, time, rule, contract, score, premium, age) → verdict feed + "show history"
  • Rule toggles ΔOI conf / Follow / Sigma / Score / Whale / 0DTE → rule builder ("alert rule fired" condition) and screens
  • 🔔 Notify, 🎯 UNIV scope, tape order, ⧉ Copy, Clear → ⋯ menu
  • Session window + per-rule counts → What-changed card + history
  • Calibration cells + journal win rates → trust strip (real bands <50 / 50–59 / 60–74 / 75+)
  • While-you-were-away digest → What-changed card

Context strips

  • Premium-flow chips (ticker, γ sign, streak, premium, PCR, σ, sparkline, call/put bar) → Money-building card; γ sign and trend also table columns
  • Following strip → Money-building card + feed "follow Nd" chips
  • Top Conviction cards (ring, tier, bias, score, notional, dte, move, E/S/T) → feed rows

Filters and table

  • Type, min vol, min score, ticker search, universe, alert threshold, sort presets, Force, CSV → Filters disclosure and ⋯ menu
  • All 16 columns + γ sign → 17-column table with chooser; simple-mode default = 10
  • Sortable headers, ★ leader, new dot, keyboard nav j/k/g/G/Enter///r → table (shortcuts printed)
  • Empty / loading / stale states → cards' third line + table copy

Smart Order Flow page

  • Watchlist, filter chips, DTE chips, legend, live feed (8 cols), selected signal (gauge, radar, rationale, GEX/RISK tags) → drill-down rail
  • Order-Flow-Imbalance sub-tab → honest placeholder: the backend has no such route; it never drew real data
  • Dealer GEX heatmap sub-tab → net-gamma bars + cumulative strip

Dealer Positioning page

  • Net GEX by strike, cumulative curve, read note → Dealers card + drill-down (flip marked, one axis)

Footer

  • Provenance line → footer
  • Vol surface (simulated) and Academy → stay removed; unreachable in the live tab today

Deliberate changes

  • Levels are labelled as model defaults (±2.5% stop, ±3.5% / ±5.5% target of spot). They are constants, so no risk-reward number is shown; "% of target travelled" is shown instead.
  • Move-since-alert is fixed — today's page multiplies it by 100 twice (+0.8% shows as +80%).
  • Plan trade writes a journal note only. It never touches the auto-trade or any order path.
  • One σ, one premium. Server-confirmed σ on the cards; raw client σ is labelled as such. Premium is always "est."
  • Colour never carries direction alone. ▲/▼ + word everywhere; colour-blind mode adds bar patterns.
