# Shared execution protocol

## Authority and ownership

Read repository instructions and applicable skills completely. Frozen App.js,
model artifacts and other frozen paths stay frozen. No live orders, paid data
calls, deployment, credential changes, Azure, swarmSPX, or X-credit work.
Keep proprietary source and data within approved tools/providers.
This reusable template grants no mutation authority. A current owner instruction
or unexpired admission card must identify repository, ref/candidate, permitted
operation and scope. Reconfirm authority on changed scope or expired admission.
Never weaken checks, discard other workers' code or invent witness evidence.

Agent 1 owns admissions and integration. Each builder owns one branch/worktree
and one explicit allowed-file list. Agent 4 reviews only and never self-merges.
A card includes task ID, owner, base SHA, branch, worktree, allowed paths,
outcomes, exclusions, test commands, dependencies, first command and expiry.
No overlapping writes. Shared docs have one writer: Agent 1. Others submit
append-only lane receipts, never overwrite control state.

## Evidence and Git

Fetch once at boot; record actual full SHAs, upstream, dirty paths, merge/rebase
state and remote head. Preserve all unknown dirt. Never guess from truncated
output: use NUL-delimited porcelain. Never wholesale merge archival/control
branches with unrelated product history.
No force push, hard reset, mass restore, cleanup, test skip, or hidden bypass.
Use a clean isolated candidate and ordinary fast-forward-compatible pushes.
Refetch before push; remote movement invalidates the planned mutation.
A stale local branch may fast-forward only after checking it has no unique work.

Tests run on the exact candidate; log command, working directory, SHA,
exit code, counts and limitations. Distinguish local reproduction from inherited
CI and independent review. A green test does not prove financial semantics.
Prove behavior through producer -> payload -> consumer -> observable output.
Do not add source-string tests to manufacture progress.
For repairs: reproduce RED, implement minimal fix, show GREEN and neighboring
regressions. Do not change weights, thresholds or model conventions incidentally.

A merge requires reviewed payload, resolved blocking findings, required CI at
current head, and base compatibility. Agent 1 rechecks head immediately before
the authorized merge. Afterwards fetch main and verify merge metadata plus
candidate ancestry or documented squash/replacement patch equivalence.
Never claim delivery from the reverse ancestry test.

Use installed GSD skills faithfully: one pass per invocation, linked contract,
SHA-pinned outcomes, trusted review trail, required checks and dependency audit.
Missing linkage or evidence means no GSD approval. Do not fabricate retrospective
normal admission for work that lacked one. Record the exception.

## Multi-day continuity and budget

Write boot.json once per session; checkpoint.json after RED, GREEN, commit,
push, review, merge, block and before context/credit exhaustion. Append events.jsonl
with UTC time, actor, task, head, action and evidence paths. Atomic checkpoint
replacement; do not truncate the event history.
Checkpoint includes actual head, dirty-owned paths, exact last result, unresolved
findings, pending command/session IDs, and one executable next command.
The tracked launch template never tries to contain its own future commit SHA.

Before restart read only the current card, shared protocol, latest checkpoint
and referenced evidence. Fetch and compare; do not replay a giant conversation.
Two identical status checks without new evidence trigger a checkpoint, not
another 'final sweep'. Select the next admitted unit or park.
On usage denial, 429 or credit exhaustion, checkpoint and park on the first
denial. No nested retries, provider switch or automatic fallback. Resume only
under fresh explicit owner direction; honor Retry-After if a retry is authorized.
For unattended cadence use a separately configured native scheduler and GSD
schedule skill, with one-pass tasks and documented stop conditions.

## Research truth

Classify every output as observed, inferred from quotes, OI proxy, model output,
or hypothesis. Preserve source, event/receive/correction times, instrument,
units, normalization, missingness, entitlement and redistribution limits.
Synthetic fixtures are explicitly synthetic. Never silently substitute stale data.
Test point-in-time joins, revised data, purging/embargo, held-out walk-forward
evaluation, costs, latency, capacity and ablations before any tradability claim.
A pinned threshold is not empirical calibration. A proxy is not dealer inventory.
Record failed hypotheses; use only verified existing data sources.
